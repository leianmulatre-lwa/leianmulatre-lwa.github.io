original mii editor · archive

These original 2007 Mii Editor files are available in the BIG LWA GitHub repository. The application uses Adobe AIR and Flash (MiiEditor/classicGUI.swf); modern browsers cannot execute that desktop program as an HTML page.

The former browser loader has been removed because it left users stuck on a Loading screen. A native web port would be needed to make the original controls functional online without Flash emulation.
